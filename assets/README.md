# Assets for the site

Drop your images here. Referenced from `_data/profile.yml` and `_data/publications.yml`:

- `profile.jpg`      — your headshot (square works best; it's shown as a circle).
- `favicon.png`      — small icon shown in the browser tab (optional).
- `cv.pdf`           — your CV (optional; linked from the header).
- `paper1_before.jpg`, `paper1_after.jpg` — 160px-wide thumbnails for the
  first publication. The "after" image is shown on hover (e.g. an animated
  teaser or result). Use `paper2_*`, ... for more papers.

Any image format works; just keep the paths in `_data/*.yml` in sync.
